I want to use GitHub's hosted runners to reduce the infrastructure and setup needed for this project, and to make it easy to point my code at a new Proxmox VE installation

My Proxmox node is running in my home LAN, so I need a VPN tunnel into it to be able to remotely execute the Terraform and Ansible code.

For this, I think the easiest solution is to use *Tailscale* with ephemeral connections in a **separate** account for this purpose. The only two devices that should connect at any time to the network is the PVE node and the GitHub actions runner.

https://tailscale.com/docs/integrations/github/github-action

I need to add a NAT forwarding rule and allow IP forwarding. I should add this to the Terraform code later

This blog post has a good guide on doing this https://proxmoxr.com/blog/proxmox-nat-masquerade

```
root@pve:~# cat /etc/network/interfaces
# network interface settings; autogenerated
# Please do NOT modify this file directly, unless you know what
# you're doing.
#
# If you want to manage parts of the network configuration manually,
# please utilize the 'source' or 'source-directory' directives to do
# so.
# PVE will preserve these directives, but will NOT read its network
# configuration from sourced files, so do not attempt to move any of
# the PVE managed interfaces into external files!

auto lo
iface lo inet loopback

iface nic0 inet manual

auto vmbr0
iface vmbr0 inet static
        address 10.0.0.222/24
        gateway 10.0.0.1
        bridge-ports nic0
        bridge-stp off
        bridge-fd 0

        post-up   iptables -t nat -A POSTROUTING -s '10.0.10.0/24' -o vmbr0 -j MASQUERADE
        post-down iptables -t nat -D POSTROUTING -s '10.0.10.0/24' -o vmbr0 -j MASQUERADE

auto vmbr1
iface vmbr1 inet static
        address 10.0.10.1/24
        bridge-ports none
        bridge-stp off
        bridge-fd 0
#MGMT

source /etc/network/interfaces.d/*
root@pve:~# echo "net.ipv4.ip_forward = 1" >> /etc/sysctl.d/99-forwarding.conf
root@pve:~# sysctl -p /etc/sysctl.d/99-forwarding.conf
net.ipv4.ip_forward = 1
```
